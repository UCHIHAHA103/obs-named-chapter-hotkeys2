# 标记快捷键 (Named Chapter Hotkeys)

OBS Studio 插件，为视频章节添加带自定义名称的快捷键。

## 功能特性

- ✅ 添加、删除、重命名章节快捷键
- ✅ 自定义颜色标记（8种颜色）
- ✅ 带注释的标记功能
- ✅ 回车确认，Shift+回车换行
- ✅ 记忆窗口位置和大小
- ✅ 记忆窗口所在显示器
- ✅ 中文界面
- ✅ **配置方案** — 快速切换不同场景的标记配置
- ✅ **配置导入/导出** — 分享和备份标记配置
- ✅ **实时标记预览面板** — 录制中实时显示标记列表
- ✅ **改进的重入保护** — 修复快速按键导致的崩溃问题

## 配置方案

支持为不同使用场景创建独立的标记方案，例如：

| 方案示例 | 适用场景 |
|----------|----------|
| 🎮 竞品分析方案 | 录制竞品游戏，标记 UI/交互/音效等 |
| 🐛 Bug 测试方案 | QA 测试，标记严重/一般/轻微 Bug |
| 🗺️ 关卡设计方案 | 关卡走查，标记难度/节奏/引导问题 |
| 📚 教程录制方案 | 录制教程，标记章节/要点/注意事项 |

### 使用方法

1. 在「标记快捷键」窗口顶部的「配置方案」区域选择或创建方案
2. 点击 💾 保存当前配置为新方案
3. 通过下拉框快速切换方案
4. 点击 🗑 删除不需要的方案

## 导入/导出

- 📤 **导出**：将当前标记配置保存为 JSON 文件，方便分享给团队成员
- 📥 **导入**：从 JSON 文件导入标记配置，支持替换或合并

## 实时标记预览面板

在 OBS 主界面的 Dock 面板中显示录制过程中的实时标记列表：

- 🔴 录制状态指示 + 实时计时
- 彩色标记列表（序号 + 时间码 + 名称 + 注释）
- 📋 一键复制 Markdown 摘要到剪贴板
- 🗑 清空标记列表

面板在「视图 → 停靠窗口」中开启。

## 注释窗口快捷键

| 操作 | 快捷键 |
|------|--------|
| 确认并关闭 | 回车 |
| 换行 | Shift + 回车 |

## 使用方法

1. 在 OBS 菜单中打开「标记快捷键」窗口
2. 添加、重命名或删除章节快捷键
3. 选择颜色（可选）
4. 勾选「启用标记注释」添加带注释的标记
5. 点击「确定」保存
